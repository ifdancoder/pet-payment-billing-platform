## О Laravel

Laravel — фреймворк для веб-приложений с выразительным и элегантным синтаксисом. Мы считаем, что разработка должна приносить удовольствие и оставлять пространство для творчества. Laravel упрощает типовые задачи веб-проектов, среди которых:

- [Простая и быстрая маршрутизация](https://laravel.com/docs/routing).
- [Мощный контейнер внедрения зависимостей](https://laravel.com/docs/container).
- Различные backend-ы для хранения [сессий](https://laravel.com/docs/session) и [кэша](https://laravel.com/docs/cache).
- Выразительная и понятная [ORM для базы данных](https://laravel.com/docs/eloquent).
- Независимые от конкретной базы данных [миграции схемы](https://laravel.com/docs/migrations).
- [Надёжная обработка фоновых задач](https://laravel.com/docs/queues).
- [Трансляция событий в реальном времени](https://laravel.com/docs/broadcasting).

Laravel — доступный и мощный инструмент для создания крупных и надёжных приложений.

## Изучение Laravel

У Laravel есть подробная [документация](https://laravel.com/docs) и большая библиотека видеоуроков, которые помогают быстро начать работу с фреймворком.

Кроме того, [Laracasts](https://laracasts.com) содержит тысячи видеоуроков о Laravel, современном PHP, модульном тестировании, JavaScript и других темах. Они помогут углубить знания на комплексных практических примерах.

На [Laravel Learn](https://laravel.com/learn) также доступны короткие уроки с реальными проектами, в которых создание Laravel-приложения начинается с нуля и параллельно объясняются основы PHP.

## Разработка с AI-агентами

Предсказуемая структура и соглашения Laravel хорошо подходят для AI-агентов, таких как Claude Code, Cursor и GitHub Copilot. Установите [Laravel Boost](https://laravel.com/docs/ai), чтобы расширить их возможности:

```bash
composer require laravel/boost --dev

php artisan boost:install
```

Boost предоставляет агенту более 15 инструментов и навыков, которые помогают разрабатывать Laravel-приложения с соблюдением лучших практик.
