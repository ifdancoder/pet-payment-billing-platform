# Архитектура

*[English version](overview.md)*

Платформа состоит из семи независимо разворачиваемых Laravel-сервисов. В
локальной среде публичный API маршрутизирует Nginx, в Kubernetes используется
ingress-nginx. Каждый сервис владеет логической базой PostgreSQL и является её
единственным владельцем записи в неё.

| Сервис | Ответственность |
| --- | --- |
| identity-service | Учётные записи, мерчанты, участники, API-ключи и токены |
| customer-service | Клиенты и платёжные контакты |
| catalog-service | Продукты и периодические тарифы |
| subscription-service | Состояние подписки и планирование продлений |
| billing-service | Инвойсы и биллинговые циклы |
| payment-service | Попытки оплаты и результаты провайдера |
| notification-service | Уведомления об успешной оплате |

## Взаимодействие и согласованность

Subscription и Notification выполняют синхронные HTTP-запросы данных клиента
или цены. Изменения состояния между сервисами передаются событиями RabbitMQ.
[ADR 0002](../adr/0002-rabbitmq-messaging.ru.md) определяет контракт сообщений,
а [каталог событий](event-catalog.ru.md) перечисляет текущих производителей и
потребителей.

Команда, изменяющая данные сервиса и создающая событие, записывает оба изменения
в одной локальной транзакции. Процессы outbox публикуют зафиксированные события.
Обработчики записывают inbox вместе с локальными эффектами. RabbitMQ может
доставить сообщение повторно, поэтому для бизнес-дубликатов также нужны
ограничения уникальности.

Код приложения и домена зависит от портов. Адаптеры Eloquent, RabbitMQ, HTTP и
провайдеров находятся в Infrastructure. Граница проверяется
архитектурными тестами сервисов.

## Платформа

Корневой Compose запускает Nginx, PostgreSQL, RabbitMQ, все API и фоновые процессы.
Kubernetes-ресурсы приложений находятся в `infrastructure/kubernetes/base`, а
опциональные общие компоненты в `infrastructure/kubernetes/platform`. Текущая
схема развёртывания описана в [Kubernetes](kubernetes.ru.md).

Общий middleware создаёт или сохраняет HTTP correlation ID и передаёт его в
синхронные вызовы других сервисов. Издатели добавляют correlation ID в заголовки
AMQP. В репозитории есть манифесты систем наблюдаемости, но приложения пока не
экспортируют телеметрию OpenTelemetry.
