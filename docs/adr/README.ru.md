# Architecture Decision Records

*[English version](README.md)*

ADR фиксируют решения, которые трудно отменить, затрагивают несколько сервисов
или не могут быть надёжно восстановлены из кода. Для отменённого решения
создаётся новый ADR; исходный остаётся историческим контекстом.

Используйте имя `NNNN-short-title.md` с нулевым дополнением и следующие разделы:

- Статус: Proposed, Accepted или Superseded by NNNN.
- Контекст: ограничения, требующие решения.
- Решение: выбранное поведение или граница.
- Последствия: стоимость, ограничения и дальнейшая работа.

Каноническая версия пишется на английском. Русские переводы используют суффикс
`*.ru.md`.
